# 自由麦 Free Say Windows 版 v1.0.0

首个独立版本。把小米蓝牙语音遥控器变成电脑的无线麦克风与快捷键面板：按住遥控器语音键说话，文字直接进入当前输入框；遥控器上的每个按键都可以自定义。

> 这是一个**独立应用**，与早期的同名前身版本互不影响，可以同时安装。首次启动会自动沿用已有配置；如果从未安装过，走一遍首次设置向导即可。

## 核心能力

- 按住遥控器语音键说话、松开即出字，兼容豆包输入法、微信输入法、Vokie 与其他语音工具。
- 遥控器每个按键的单击、双击、长按都可分别映射为快捷键、鼠标动作或启动应用。
- 返回、音量+、音量− 等遥控器专有按键也可接管；首次开启需要一次 Windows 授权，之后长期有效。
- 遥控器不在内置型号里也能用：上传照片、命名按键、选择键位、在照片上标出位置即可。
- 按键映射页的卡片可以拖动：上下移动、拖过中线换列，其它卡片自动让位。

## 本版修复

- 松开语音键后输入法不再停在等待状态：以前需要再点一次才结束，现在松手即结束。
- 长句不再中途失声：此前按住说十几秒会被截断，之后无论说多久都收不到声音，现在可以连续说完。
- 说完之后键盘、鼠标侧键与输入法的快捷键设置恢复正常：此前偶发按键错乱，连输入法自己的「设置快捷键」界面都录不到键。
- 「全按键支持」不再打不开：修复了开关拨上去又弹回、提示找不到授权的问题。
- 「全按键支持」改为只需授权一次：第一次开启弹一次 Windows 授权窗口，选「是」之后一直有效。
- 自定义遥控器的照片显示完整：此前顶部会被裁掉一截，标记在那一带的按键连圆点都看不见。
- 「核对」能录到返回、音量+、音量−：此前按这三个键界面毫无反应，只能超时退出。
- 录入按键时不再接管整个键盘：现在只有本应用在前台时才拦截，切到别的程序可以照常打字。

## 安装说明

- 按当前用户安装，日常不要用管理员身份运行。
- 安装包暂未做 Windows 代码签名，首次运行时可能出现 SmartScreen 提示。
- 如果电脑上装过早期版本，首次启动会自动把配置搬过来；旧版本不受影响，可以随时回退。
- 版本升级路径从本版开始独立计算，不再与早期版本共用版本号。

## 已知限制

- 遥控器自带的麦克风只在按住按键期间工作。如果输入法的录音设备选的是虚拟声卡通道，松手后就没有声音；改用电脑麦克风则可以随说随停。
- 按住说话快捷键最多两个键（例如 Ctrl + M）。三个键及以上的组合无法通过遥控器上报，保存时会被拒绝。
- ARM64 电脑可以使用基础语音与按键功能；本次安装包未携带 ARM64 的按键接管组件。
