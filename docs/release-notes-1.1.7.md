# 自由麦 FreeSay Windows 版 v1.1.7

本次版本集中在两件事：**自定义遥控器页的布局重做**，以及**切换遥控器后按键页不跟手**的修复。同时品牌名统一为 `FreeSay`（去掉中间空格）。

## 自定义遥控器页：布局重做

- **列表卡取消**：当前只支持定义一只自定义遥控器，左侧的遥控器卡片已移除，信息并入顶部信息卡（名称、按键数、绑定状态、设为当前 / 复制内置配置 / 删除）。
- **名称就地编辑**：点一下即可改，失焦后转灰只读，再次点击可继续编辑；不再占用一行 label 文字。
- **照片按比例完整显示**：照片区固定高度、宽度随图片比例自适应，长条遥控器照片不再被裁切或压扁。
- **按键表格**：名称 / 键位 / 核对 / 位置 / 删除五列全部可见，无横向滚动；表头「核对（可选）」简化为「核对」。
- **副标题与主按钮**：说明文字不再挤成三行；「新建遥控器」不再折行。

## 修复

- **点「设为当前」后按键页没跟过来**：两个原因——本页从未发过跳转事件；且保存档案与切换按键配置存在竞态。现在按「保存 → 切换按键档案 → 跳到按键页」串行执行。
- **按键页照片/按键被重置回内置**：刚连接后连接快照的 token 可能尚未就绪，原逻辑据此判定「无匹配」并把当前布局重置为内置。现在拿不到 token 时不做判定。
- **推荐页**：卡片列数改为断点固定（1/2/3 列），宽窗口不再挤成四列；修复标题与正文之间的大段空白、长文案溢出与裁切；兼容性说明从标题旁的徽标改为正文末尾小字。
- **桌面图标白底**：应用图标与安装包图标都重新生成为透明圆角（16/24/32/48/64/256 全尺寸），并统一为同一套品牌图（此前安装包用深色几何图、程序内用浅色手绘图，两套不一致）。

## 品牌

- 产品名、窗口标题、开始菜单目录、界面文案统一为 `FreeSay`（无空格）。
- 安装目录随之变为 `...\Programs\FreeSay\`；从旧版本升级时旧目录会保留，可手动卸载旧版本，配置数据在 `%LOCALAPPDATA%\SayAll`，不受影响。

## 安装说明

- 按当前用户安装，日常不要用管理员身份运行。
- 安装包暂未做 Windows 代码签名，首次运行可能出现 SmartScreen 提示。
- 若桌面快捷方式仍显示旧图标，删除后从开始菜单重新创建即可（Windows 图标缓存）。
